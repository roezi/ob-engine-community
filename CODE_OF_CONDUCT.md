# Code of Conduct

OB Engine Community aims to be a respectful and practical open-source project.

## Expected behavior

- Be respectful.
- Give constructive feedback.
- Focus on the technical problem.
- Help maintain a safe and welcoming environment.

## Unacceptable behavior

- Harassment
- Personal attacks
- Spam
- Sharing private credentials or secrets
- Publishing security issues publicly before responsible disclosure

## Enforcement

The maintainer may remove comments, close issues, or block users who violate this code of conduct.
